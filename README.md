# 🚀 گنگ نت پنل (GangNet Panel)

یک پنل مدیریتی حرفه‌ای و مدرن برای مدیریت کانفیگ‌های VLESS روی vps

---

## ✨ ویژگی‌ها

- داشبورد مدرن: با آمار لحظه‌ای، نمودار و کارت‌های زیبا
- سیستم ورود حرفه‌ای: با افکت شیشه‌ای و انیمیشن
- مدیریت کامل کاربران: ساخت، حذف، فعال/غیرفعال، حجم و زمان
- لینک ساب اختصاصی: برای هر کاربر با دامنه دلخواه
- API: برای اتصال به ربات و برنامه‌های دیگه
- امنیت: کوکی سشن و رمز پیش‌فرض قوی
- ربات تلگرام: فروش خودکار کانفیگ
- تِم تاریک: با آکسان بنفش
